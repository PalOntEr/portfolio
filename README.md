# PalOntEr // Developer Monograph & Portfolio

A high-performance personal portfolio showcasing software engineering work authored by **Max Zertuche** ([@PalOntEr](https://github.com/PalOntEr)).

Designed around an "Editorial Technologist" aesthetic inspired by printed engineering monographs, architectural publications, and high-craft hardware manuals.

---

## 🧭 What is Featured

* **Works Catalog (`/projects`)**: A numbered index of technical engineering projects with deep-dive technical breakdowns (problem constraints, architecture decisions, and performance highlights):
  * **GPU & Systems**: Hardware-accelerated processing engines (e.g. *PhotoHub* with custom NVIDIA CUDA kernels, C++, and .NET).
  * **Low-Level Graphics & Game Engines**: Custom rendering engines authored from scratch (e.g. *AntDefender* in C++, raw DirectX 11, and HLSL).
  * **Full-Stack & Cloud Platforms**: Resilient web applications, distributed platforms, and real-time multiplayer systems.
* **Engineering Dossier (`/dossier`)**: Summary of core competencies, low-level graphics and distributed systems proficiencies, hackathon accolades, and colophon.
* **Interactive Schematics**: Hardware and GPU-inspired interactive wireframe visuals rendered via WebGL / OGL and GSAP.

---

## 🛠️ Tech Stack

* **Framework**: [Astro 6](https://astro.build/) (Static Site Generation / SSG)
* **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
* **Interactivity & UI**: [React 19](https://react.dev/), [Lucide Icons](https://lucide.dev/)
* **Graphics & Animation**: [OGL](https://github.com/oframe/ogl) (minimal WebGL library) & [GSAP](https://gsap.com/)
* **Deployment**: GitHub Pages

## 🚀 Getting Started

### Prerequisites

* Node.js `>= 22.12.0`
* npm / pnpm / yarn

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/PalOntEr/Portfolio-web-page.git

# Navigate to project directory
cd Portfolio-web-page

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build static output for production
npm run build
```
